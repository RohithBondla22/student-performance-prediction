# Student Performance Prediction

A beginner-friendly Machine Learning web application that predicts a student's final score based on academic information.

## Features

- Student performance prediction
- Machine Learning model
- Flask REST API
- Web-based user interface
- Input validation
- Performance classification
- Responsive design

## Input Features

The model uses:

- Study hours per day
- Attendance percentage
- Previous exam score
- Assignments completed

## Machine Learning Algorithm

The project uses Linear Regression to predict the student's final score.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Joblib
- HTML
- CSS
- JavaScript
